# 점과 선 (Connecting the Dots)

> “앞을 내다보며 점을 이을 수는 없습니다. 오직 뒤를 돌아볼 때만 이을 수 있죠.”
> — 스티브 잡스, 2005 스탠퍼드 졸업 연설

하루하루의 경험을 **점**으로 기록하고, 뒤돌아보며 과거의 점과 **선**으로 이어
나의 성장을 별자리처럼 보여주는 자기계발 모바일 앱(PWA)입니다.

## 화면 (v2 — 앱스토어 상위 앱 분석 반영, [BENCHMARK.md](BENCHMARK.md) 참고)
- **온보딩** — 잡스 인용 → 되고 싶은 나(정체성) → 추천 습관 고르기
- **오늘** — 🔥 연속 기록, 7일 진행률 링, 아침·오후·저녁 습관 원탭 체크(축하 애니메이션·진동), 오늘의 마음, 오늘의 점과 질문, 돌아보기(과거의 점과 잇기)
- **별자리** — 경험의 점이 나선 위에 놓이고, 이은 점들이 별자리가 됩니다.
- **성장 지수** — 주식처럼 100에서 시작해 기록할수록 오르고, 아무것도 안 한 날은 조금 내려갑니다. 상승은 빨강, 하락은 파랑입니다. 기간(1주~전체)을 고를 수 있고, 차트를 손가락으로 훑으면 그날의 지수가 보입니다. 오늘 탭에는 작은 시세판이 있습니다.
- **성장** — 레벨(점→선→면→…→우주)과 XP, 되고 싶은 나에게 던진 표, 습관의 선(연속된 날은 선으로 이어짐), 마음의 흐름과 인사이트, 12주 기록, 배지 12종
- **나** — 프로필, 습관 관리(요일·시간대), 백업/복원

## 계속하게 만드는 장치
| 장치 | 원리 | 참고한 앱 |
|---|---|---|
| **연속 기록 보호권** — 7일 연속마다 1개(최대 2개). 하루를 놓치면 자동으로 연속 기록을 지켜줍니다 | 한 번 끊겨서 포기하는 것을 막음 | Duolingo |
| **오늘의 전망** — “남은 습관 2개를 하면 +6 더 오릅니다” / “오늘 기록이 없으면 지수가 0.31 내려갑니다” | 얻을 것과 잃을 것을 눈앞에 보여줌 | 증권 앱 |
| **신고가** — 성장 지수가 역대 최고를 찍으면 하루 한 번 알림 | 매일의 작은 승리 | 증권 앱 |
| **다음 목표** — 가장 가까운 배지와 남은 거리 | 목표에 가까울수록 더 하고 싶어짐 | Habitica, Duolingo |
| **다시 오셨네요** — 3일 이상 쉬고 돌아오면 “가장 쉬운 습관 하나만” | 새 출발 효과, 죄책감 대신 환영 | Finch, Fabulous |
| **오늘의 문장** — 잡스 스탠퍼드 연설에서 하루 한 문장 | 이 앱을 쓰는 이유를 상기 | — |

## 자주, 가볍게 드나들 수 있게 (UX)
- **3초 기록:** 오늘 탭에서 바로 쓰고 엔터를 치면 점이 찍힙니다. 과거와 잇기와 메모는 나중에 해도 됩니다.
- **지금 할 것:** 현재 시간대(아침·오후·저녁) 습관 묶음에 ‘지금’ 표시가 붙습니다.
- **다시 들어올 이유:** 홈 화면 앱 아이콘 배지와 창 제목에 오늘 남은 습관 수가 뜹니다.
- **아이콘 바로가기:** 앱 아이콘을 길게 누르면 ‘점 찍기’, ‘성장 지수’, ‘별자리’로 바로 갑니다.
- **부드러운 움직임:**
  - 탭은 방향에 맞춰 밀려 들어오고, 같은 탭을 다시 누르면 맨 위로 갑니다.
  - 스크롤하면 작은 제목 막대가 나타납니다.
  - 시트는 아래로 끌어내려 닫을 수 있습니다.
  - 오늘 탭에서 좌우로 밀면 날짜가 넘어갑니다.
  - 습관 체크는 화면을 다시 그리지 않고 그 자리에서 튀어 오릅니다.
- **실수해도 괜찮게:** 삭제할 때 확인창 대신 ‘되돌리기’를 4초 동안 보여줍니다.

## 디자인 원칙
- 검정 배경, 흰 글자, 얇은 선. 색은 분야를 나타내는 작은 점에만 씁니다.
- 숫자는 가늘고 크게, 나머지는 작고 조용하게 씁니다.
- 이모지·그라데이션·색종이 효과 없이, 진행도 점과 선으로만 보여줍니다.
- iOS식으로 묶인 목록, 시트, 반투명 탭바를 씁니다.

## 실행
```bash
cd dots
python3 -m http.server 8000
# 휴대폰/브라우저에서 http://<컴퓨터 IP>:8000 접속
```
HTTPS(예: GitHub Pages)로 배포하면 휴대폰에서 “홈 화면에 추가”로 앱처럼 설치하고 오프라인에서도 쓸 수 있습니다.

## 파일
- `index.html` 화면 구조 · `style.css` 디자인 · `app.js` 동작
- `manifest.webmanifest`, `sw.js`, `icon.svg` 앱 설치/오프라인용
