# 스포츠 한입 쇼츠 편집기

세로 쇼츠(1080×1920)를 템플릿으로 빠르게 만들고, 한 번 내보낸 파일을
유튜브 쇼츠, 틱톡, 네이버 클립, 카카오톡 숏폼에 **똑같이** 올리기 위한 도구입니다.

설치할 것은 없습니다. `index.html`을 **크롬**이나 **엣지**로 열면 바로 쓸 수 있습니다.

---

## 1. 영상 템플릿 구성안

### 공통 규칙

| 항목 | 기준 |
|---|---|
| 화면 | 세로 9:16, 1080×1920 |
| 길이 | 20~30초 (끝까지 보는 비율이 가장 중요) |
| 첫 2초 | **결론부터**. "9회말 끝내기!"처럼 결과를 먼저 보여준다 |
| 자막 | 영상에 직접 넣기 (소리 끄고 보는 사람이 많음). 한 화면에 2줄 이하 |
| 강조 | 핵심 단어 1~2개만 노란색 (`[대괄호]`로 감싸기) |
| 전환 | 3~5초마다 장면을 바꿔서 지루할 틈을 없앤다 |
| 가림 영역 | 위쪽 8%, 아래쪽 20%, 오른쪽 버튼 줄에는 중요한 글자를 두지 않는다 |
| 마지막 | 질문으로 끝내서 댓글을 유도하고, 구독 문구를 넣는다 |
| 워터마크 | 좌상단에 채널 이름 (다른 채널이 퍼가도 출처가 남음) |

### 템플릿 A: 경기 결과 요약 (30초) — 매일 올리는 기본형

| 시간 | 장면 | 내용 예시 |
|---|---|---|
| 0~2초 | 훅 | `오늘의 KBO` / "9회말 끝내기! LG 3연승" |
| 2~5초 | 스코어보드 | LG 5 : 4 두산, "잠실 · 9회말 끝내기" |
| 5~10초 | 핵심 장면 1 | "1회초 선제 2점 홈런" |
| 10~15초 | 핵심 장면 2 | "7회 동점 적시타, 승부는 다시 원점" |
| 15~20초 | 핵심 장면 3 | "9회말 2사 만루, 대타의 끝내기 안타" |
| 20~26초 | 기록 카드 | 오늘의 MVP: 4타수 3안타 3타점 |
| 26~30초 | 질문 + 구독 | "오늘 MVP는 누구? 댓글로 알려주세요" |

### 템플릿 B: 선수 기록 (20초) — 대기록, 이정표가 나온 날

| 시간 | 장면 | 내용 예시 |
|---|---|---|
| 0~2초 | 훅 | `대기록` / "시즌 40홈런 달성!" |
| 2~7초 | 기록의 순간 | "6회말 우중간, 비거리 135m 대포" |
| 7~14초 | 기록 카드 | 홈런 40 / 타점 112 / 타율 0.312 / OPS 1.021 |
| 14~17초 | 의미 | "구단 역대 최초 40홈런 타자" |
| 17~20초 | 질문 + 구독 | "50홈런까지 갈까? 댓글로 예상해 주세요" |

### 템플릿 C: 이적 · 뉴스 속보 (25초) — 해외축구, 농구 이슈

| 시간 | 장면 | 내용 예시 |
|---|---|---|
| 0~2초 | 훅 | `속보` / "오피셜, OOO 이적 확정" |
| 2~7초 | 무슨 일? | "A팀에서 B팀으로 전격 이적" |
| 7~13초 | 계약 조건 | 기간 4년 / 이적료 / 주급 |
| 13~18초 | 영향 | "B팀 중원에 즉시 전력 합류" |
| 18~22초 | 팬 반응 | "드디어 왔다", "우승 가자" |
| 22~25초 | 질문 + 구독 | "이번 이적 성공할까요?" |

### 제작 순서 (경기 끝나고 1시간 안에 올리기)

1. 경기 종료 → 템플릿 A 불러오기 (1분)
2. 점수, 자막, MVP 기록 고치기 (5~10분)
3. 사진이나 직접 찍은 영상 넣기 (5분)
4. 내레이션 녹음 파일 넣기 (선택)
5. 내보내기 → 4개 플랫폼에 같은 파일 올리기

> **저작권 주의**: 중계 화면을 그대로 쓰면 신고나 수익 박탈을 당할 수 있습니다.
> 직접 찍은 사진, 공식적으로 사용이 허락된 이미지, 그래픽 위주로 만드세요.
> KBO 영상은 권리사의 최신 짧은 영상 가이드라인을 확인하세요.

## 2. 편집기 사용법

### 화면 구성

- **왼쪽 (장면 순서)**: 장면 목록. 순서 바꾸기(↑↓), 복제, 삭제, 새 장면 추가
- **가운데 (장면 편집)**: 고른 장면의 글자, 길이, 사진/영상, 색 수정
- **오른쪽 (미리보기)**: 재생(스페이스바), 시간 이동, 가림 영역 표시, 영상 내보내기

### 장면 종류

| 종류 | 용도 |
|---|---|
| 훅 (결론 먼저) | 첫 2초. 라벨 + 큰 제목이 튀어나옴 |
| 스코어보드 | 두 팀 이름, 점수, 팀 색. 이긴 팀에 WIN 표시 |
| 장면 + 자막 | 사진/영상 위에 자막 (위, 가운데, 아래 선택) |
| 기록 카드 | 선수 이름 + 기록 줄 최대 5개 (`항목: 값` 형식) |
| 질문 + 구독 유도 | 댓글 질문 + 채널 이름 + 구독 버튼 |

### 팁

- 자막에서 `[끝내기]`처럼 대괄호로 감싸면 강조색으로 바뀝니다.
- 사진은 화면을 꽉 채우고 천천히 확대됩니다. 영상은 소리 없이 재생됩니다.
- 배경음악과 내레이션은 **채널 설정**에서 넣고 볼륨을 맞춥니다.
- **업로드 문구**에 제목과 해시태그를 적어두면 버튼 한 번으로 복사됩니다.
- 글자와 설정은 브라우저에 자동 저장됩니다. **사진, 영상, 음악 파일은 저장되지 않으니**
  다시 열면 새로 넣어야 합니다. 다른 컴퓨터로 옮길 때는 **프로젝트 저장**을 쓰세요.

### 내보내기

- **영상 내보내기**를 누르면 영상 길이만큼 실제로 재생하면서 녹화합니다.
  30초 영상이면 30초가 걸리고, 그동안 **탭을 벗어나면 안 됩니다**.
- 최신 크롬/엣지는 **MP4(H.264)** 로 저장됩니다. 지원하지 않는 브라우저는 WebM으로 저장되는데,
  MP4만 받는 곳에 올리려면 변환이 필요합니다. 예시 (ffmpeg):

  ```
  ffmpeg -i 입력.webm -c:v libx264 -pix_fmt yuv420p -c:a aac 출력.mp4
  ```
