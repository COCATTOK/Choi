# 맛집 쇼츠/릴스 자동 편집기

영상만 넣으면 인스타 릴스/쇼츠용 9:16 맛집 영상이 나옵니다. (필요: Python 3.8+, ffmpeg)

```bash
# 가장 간단하게 (파일 여러 개 또는 폴더째로)
python shorts_editor.py 영상1.mp4 영상2.mov
python shorts_editor.py ./촬영폴더

# 자막/음악까지
python shorts_editor.py ./촬영폴더 -n "성수동 돈카츠 맛집" -i "서울 성수동 123-4" -i "히레카츠 14,000원" --bgm music.mp3 -o reels.mp4
```

## 자동으로 해주는 것
1. 영상을 2.4초 단위로 쪼개 색감(채도)·움직임·밝기로 점수화 → 베스트 컷만 선별
2. 가장 먹음직스러운 컷을 맨 앞(훅)으로 배치
3. 1080x1920 변환 (가로 영상은 블러 배경, `--fit crop` 이면 꽉 채움)
4. 푸드 색보정(채도↑ 따뜻한 톤 선명도↑), 전환 효과(fade/slide/wipe)
5. 자막: 가게명(상단) · 정보(하단) · 마지막 CTA "저장해두고 가보세요!"
6. 음량 -14 LUFS 정규화, BGM 믹스(`--bgm`, 원본 소리 제거 `--mute`)

## 주요 옵션
`-t` 목표 길이(기본 20초) · `--seg` 컷 길이 · `--cta ""` CTA 끄기 · `--no-hook` · `--font` 폰트 지정
(폰트는 나눔/Noto/맑은고딕/AppleSD 자동 탐색)
