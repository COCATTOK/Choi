# 경비원 월급 계산기 — 페이지 제목안·메타설명 제안

## 제목안 (3개)
1. **경비원 월급 계산기 | 격일제·교대제 야간수당과 최저임금 확인 (2026·2027)** — 검색어(경비원 월급 계산기)를 맨 앞에, 연도로 최신성 강조 (46자)
2. **내 경비원 월급, 제대로 받고 있을까? 야간수당·휴게시간·감시단속 승인 총정리** — 운영자 문단의 문제의식("내 월급이 제대로 계산된 건지")을 그대로 살린 질문형 (43자)
3. **경비원 야간수당 계산기: 3교대·24시간 격일제 월급과 최저임금 한 번에** — 근무형태 두 가지를 명시, 가장 짧음 (40자)

## 메타설명 (80자 이내, 글자 수는 공백 포함)
1. 격일제·교대제 경비원 월급과 야간수당을 계산하고 최저임금 충족 여부를 확인하세요. 감시·단속 승인과 휴게시간 기준도 정리했습니다. (72자)
2. 격일제·3교대 경비원의 월급·야간수당을 계산하고 최저임금 충족 여부까지 확인하세요. 승인·휴게시간 기준 정리. (61자)
3. 내 경비원 월급, 제대로 계산됐을까? 격일제·교대제 야간수당과 최저임금을 2026·2027년 기준으로 바로 확인하세요. (66자)

추천: 제목 1 + 메타설명 1 (검색어와 내용 범위가 가장 정확하게 드러남).

## 워드프레스 적용 순서
계산기 위·아래 글과 계산기는 각각 **사용자 정의 HTML 블록**으로 붙여넣습니다.

1. `1_위쪽글.html` — 운영자 문단, 2줄 요약, 목차
2. `2_계산기.html` — 계산기 (`build-wp.js` 로 생성되므로 직접 수정하지 말고 원본 `../guard-salary-calculator.html` 을 고친 뒤 다시 생성)
3. `3_아래쪽글.html` — 승인 설명, 표, 계산 예시, FAQ 6개, 관련 링크 자리, 출처

- 목차 링크(`#guard-calc`, `#gcs-*`)는 세 블록이 같은 페이지에 있을 때 동작합니다.
- 관련 링크 자리(`data-slot`)의 `href="#"` 는 게시 전 실제 주소로 바꿔 주세요. '야간·연장수당 계산기'는 준비 중이라 링크 없이 표기했습니다.
- 모든 CSS는 `#guard-calc` / `.gc-article` 안쪽으로만 적용되어 테마 스타일을 건드리지 않습니다.
- 재생성: `node build-wp.js && node build-articles.js` · 점검: `node wp-scope.test.js`
