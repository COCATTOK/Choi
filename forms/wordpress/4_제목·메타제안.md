# 경비원 월급 계산기 — 페이지 제목안·메타설명 제안

## 제목안 (3개)
1. **경비원 월급 계산기 | 격일제·교대제 야간수당과 최저임금 확인 (2026·2027)** — 검색어(경비원 월급 계산기)를 맨 앞에, 연도로 최신성 강조 (46자)
2. **내 경비원 월급, 제대로 받고 있을까? 야간수당·휴게시간·감시단속 승인 총정리** — "내 월급이 제대로 계산된 건지"라는 독자의 궁금증을 그대로 살린 질문형 (43자)
3. **경비원 야간수당 계산기: 교대제·24시간 격일제 월급과 최저임금 한 번에** — 근무형태 두 가지를 명시, 가장 짧음 (40자)

## 메타설명 (80자 이내, 글자 수는 공백 포함)
1. 격일제·교대제 경비원 월급과 야간수당을 계산하고 최저임금 충족 여부를 확인하세요. 감시·단속 승인과 휴게시간 기준도 정리했습니다. (72자)
2. 격일제·교대제 경비원의 월급·야간수당을 계산하고 최저임금 충족 여부까지 확인하세요. 승인·휴게시간 기준 정리. (61자)
3. 내 경비원 월급, 제대로 계산됐을까? 격일제·교대제 야간수당과 최저임금을 2026·2027년 기준으로 바로 확인하세요. (66자)

추천: 제목 1 + 메타설명 1 (검색어와 내용 범위가 가장 정확하게 드러남).

## 워드프레스 적용 방법
**`wp-guard-calc-all.html` 의 내용을 통째로 복사해서 '사용자 정의 HTML' 블록 하나에 붙여넣으면 됩니다.**
페이지에는 아래 순서로 나옵니다.

1. 2줄 요약
2. 계산기
3. 목차
4. 설명글 (승인이란 / 달라지는 것 / 휴게시간 판단 기준 / 야간수당 계산법 / 계산 예시 / FAQ / 출처)

- 목차 링크(`#gcs-*`)는 합본이 한 블록에 들어 있으므로 그대로 동작합니다.
- 관련 링크의 `data-slot` 은 게시 전 실제 주소가 필요하면 바꿔 주세요. '야간·연장수당 계산기'는 준비 중이라 링크 없이 표기했습니다.
- 계산기 스크립트는 **base64 로 인코딩**되어 있고, `&` `<` `>` 가 없는 짧은 로더가 풀어서 실행합니다. 워드프레스가 스크립트 안의 `&&` 를 `&#038;&#038;` 로 바꿔 `Invalid or unexpected token` 오류가 나던 문제를 피하기 위해서입니다. 스크립트 부분은 사람이 읽거나 고치는 용도가 아니며, 수정은 원본 `../guard-salary-calculator.html` 에서 한 뒤 다시 생성하세요.
- 모든 CSS는 `#guard-calc` / `.gc-article` 안쪽으로만 적용되어 테마 스타일을 건드리지 않습니다.
- 따로 붙이고 싶을 때를 위해 조각 파일도 있습니다: `1_위쪽글.html`(요약) · `2_계산기.html` · `3_아래쪽글.html`(목차+설명글).
- `preview-all.html` 은 합본에 테마 견본(h1·버튼·문단)을 붙인 테스트용 미리보기입니다. 업로드용이 아닙니다.
- 재생성: `node build-wp.js && node build-articles.js` · 점검: `node wp-scope.test.js`
