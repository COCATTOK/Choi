# 제갈량 상소문 (諸葛亮 上疏文)

매일 **오전 7시**, 그리고 **컴퓨터를 켜고 로그인할 때마다** 제갈량이 두루마리 상소문을 올립니다.

- **一. 클로드 코드를 부리는 법** — 초보를 위한 실전 조언 (2,000자 이상)
- **二. 주공의 대업과 삶의 방향** — 사업·삶에 대한 조언 (3,000자 이상)
- **今日一言** — 오늘의 한 구절

세로쓰기 두루마리가 기본이고, 아래 버튼으로 가로쓰기·글자 크기를 바꿀 수 있습니다. (마우스 휠을 내리면 두루마리가 왼쪽으로 펼쳐집니다.)

## 어떻게 "나에 대한" 조언을 하나요?

하루에 한 번, 이 컴퓨터의 **클로드 코드**(`claude -p`)가 `prompt.md`의 지시대로 아래 자료를 읽고 그날의 상소를 새로 써서 `data/today.js`에 저장합니다. (클로드에게는 파일 읽기·쓰기 권한만 줍니다.)

1. `about-me.md` — 주공이 직접 적는 자기소개·사업·고민 (**꼭 채워 주세요**)
2. `~/.claude/history.jsonl` — 이 컴퓨터에서 클로드 코드에 입력했던 최근 200개의 요청
3. 어제의 상소 — 같은 조언을 되풀이하지 않도록

> ⚠️ claude.ai 웹/앱에서 나눈 대화는 이 컴퓨터에서 자동으로 읽을 수 없습니다.
> 그쪽에서 나눈 중요한 고민은 `about-me.md`에 옮겨 적어 주세요.

클로드 코드가 없거나 실패하면, 미리 써 둔 **기본 상소문**이 대신 올라옵니다.
하루에 한 번만 새로 쓰고(오전 7시 또는 그날 첫 로그인), 그 뒤로는 같은 상소를 다시 보여 줍니다.

## 설치

먼저 이 폴더(`zhuge-sangsomun`)를 컴퓨터에 받아 두세요. 폴더를 옮기면 설치를 다시 해야 합니다.

### Windows

1. `windows\install.cmd` 를 더블클릭 (파란 "PC 보호" 창이 뜨면 「추가 정보」 → 「실행」)
2. 끝! 바로 첫 상소가 뜨고, 이후 매일 07:00와 로그인 때마다 뜹니다.
   (Edge의 깔끔한 앱 창으로 열립니다. 작업 스케줄러에 `ZhugeLiang-Sangsomun` 이름으로 등록됩니다.)

- 지금 바로 다시 보기: `windows\open-now.cmd`
- 해제: `windows\uninstall.cmd`

### macOS

1. 이 폴더를 **홈 폴더 바로 아래**(예: `~/zhuge-sangsomun`)에 두세요.
   (데스크탑·문서·다운로드 폴더에 두면 macOS 보안 때문에 자동 실행이 막힐 수 있습니다.)
2. 터미널에서 `bash ~/zhuge-sangsomun/mac/install.command`
3. 해제: `bash ~/zhuge-sangsomun/mac/uninstall.command`

## 파일 구성

| 파일 | 역할 |
|---|---|
| `sangsomun.html` | 두루마리 상소문 화면 (기본 상소문 포함) |
| `prompt.md` | 제갈량에게 주는 지시문 (말투·분량·형식). 원하는 대로 고쳐도 됩니다 |
| `about-me.md` | 주공에 관한 기록 — 자세할수록 조언이 날카로워집니다 |
| `windows/` | Windows 설치·실행 스크립트 (작업 스케줄러, 일반 cmd 파일) |
| `mac/` | macOS 설치·실행 스크립트 (launchd) |
| `data/` | 매일 생성되는 상소와 상태 (자동 생성, git에 올리지 않음) |
